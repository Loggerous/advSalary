# advSalary | 1.16 - 1.21+
This plugin will add a unique salary system for different privileges to your server with a customizable menu and LuckPerms groups in the plugin configuration!
## Permissions
- advsalary.admin - Full access to plugin commands
- advsalary.claim - Opportunity claiming salary for the player
## Commands
- /advsalary reload - Reloading plugin config
- /advsalary uncooldown [player] - Remove cooldown for the player
- /salary - Open menu for claim a salary
## Placeholders
- %time% - Time until next salary
- %prefix% - Plugin prefix
- %salary% - Outputs text from display to config.yml
- %player_group% - Show player group from LuckPerms
- %player% - Player display name
